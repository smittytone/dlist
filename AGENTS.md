# Project Notes for AI Agents

## Markdown formatting

When writing or editing Markdown files, format paragraphs and list items so each one is a single unwrapped line (no manual line breaks in the middle of a paragraph). Use blank lines only as separators between paragraphs, list items, headings and code blocks.

## Style

Do not use the Oxford (serial) comma. In a list of three or more items, omit the comma before the final "and" or "or" (e.g. "paragraphs, list items and headings", not "paragraphs, list items, and headings").
